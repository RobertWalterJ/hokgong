# PWA audit, 2026-11-03

App: Hok Gong. Published at https://robertwalterj.github.io/hokgong/ (one shared origin with Robert's other apps).

Jargon: a "service worker" is the small script that lets the app work offline. A "cache" is the phone's saved copy of files. "Manifest id" is the name Chrome uses to tell installed apps apart.

## What was checked

The nine shared-origin rules: manifest id, scope and start_url, cache cleanup, no global caches.match(), manifest never cache-first, icons, storage names, big precache, and navigation handling. Source files and the generated docs/ or site/ folder were both read.

## Findings

| Rule | Result |
|---|---|
| 1 Manifest id | OK. id is /hokgong/. |
| 2 Scope and start_url | OK. Both are ".". |
| 3 Cache cleanup | OK. Deletes only hokgong- caches, keeps its own audio and deck caches on purpose. |
| 4 Global caches.match() | OK. Not used. |
| 5 Manifest not cache-first | OK. The worker never stores or serves it from cache. |
| 6 Icons | OK. 192, 512 and maskable 512 with the art inset. |
| 7 Storage names | OK. Keys hokgong.v1 and hokgong.voice. Caches start with hokgong-. |
| 8 Big precache | OK. Every file is added on its own and failures are ignored. |
| 9 Navigation handling | OK. Nothing overwrites index.html except the real page. |
