# Dyslexia audit — 20 September 2026

Run it yourself: `node audits/run-dyslexia.mjs`. It runs at every build and
fails it, exactly like the colour audit.

The reference is the British Dyslexia Association style guide: sans-serif type,
generous size and line spacing, left-aligned rather than justified or centred,
no blocks of capitals, no italics for emphasis, off-white rather than pure
white, and nothing that depends on reading quickly.

## What it found

**Two failures, both mine, both in the redesign I had just finished.**

1. **Blocks of capitals.** The new design set the section labels and the
   question prompt in uppercase with wide letter-spacing — "SAY THIS IN
   CANTONESE". It looks contemporary and it is one of the harder things to
   read: capitals remove the word-shape that a reader uses to recognise a word
   without decoding it. Both are now sentence case, kept quiet by size and
   colour instead.

2. **Centred prose.** The word card centred its whole contents, including the
   example sentence and the source line. Centred text gives every line a
   different starting point, so the eye has to hunt for the start of the next
   one. Only the character and its reading are centred now.

**One check passed on a technicality**, which is worth recording: "the serif
reading face can be switched to sans" passed because the words `--read-font`
appeared in the code, not because a setting existed. It does now — Settings →
Plain sans-serif for meanings — and the check tests for the setting.

## What passes

- Body text 18px, line spacing 1.65, a larger-text setting on top of that, and
  the phone's own setting respected.
- Off-white page, never pure white.
- Nothing justified, nothing italic, nothing in capitals.
- Read-aloud throughout: on every meaning, every quotation, every explanation
  on the tones, grammar, context, progress and about screens. The text read
  aloud is the text on screen — held in a constant so the two cannot drift.
- **Nothing counts down, nothing is timed, nothing disappears.** There is not a
  single repeating timer in the app. The only delay is 220ms, which starts the
  audio on a listening question.
- Animation is disabled entirely for anyone whose phone asks for less motion.

## What the audit cannot check

Whether it is comfortable to read for half an hour. That one is yours, and if
any of it is tiring in use, the fix is a setting rather than an argument.
